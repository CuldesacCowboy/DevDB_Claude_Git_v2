# Kindergarten Classroom — Room Analysis & Overhead Model

Built from 14 photos of Room 4 (kindergarten), August 2026. Personal project — separate from DevDB.

## Deliverable

`kindergarten_room_map.html` — a self-contained interactive overhead model of the classroom.
Open it in any browser (double-click the file, no server needed). Four modes:

1. **Room map** — top-down schematic with zone overlay and furniture labels.
2. **Seating chart** — paste the class roster, tap a name then tap a carpet dot or chair to
   place it (or auto-assign carpet spots). Saved in the browser; printable.
3. **Center rotations** — enter groups, generate a round-robin rotation across the 6 stations
   marked on the map; printable schedule table.
4. **Sub guide** — 10 numbered callouts covering doors, restroom, dismissal-notes chart, prep
   nook, emergency exit route, plus a free-text notes box; printable one-sheet.

## Room layout (as reconstructed)

- **Front wall:** pull-down projection screen (ceiling projector), heart posters, wood-look
  bulletin boards, Learning Objectives board, flag, teacher cart.
- **Window wall:** two large windows (birthday board on glass), mailbox cubbies in the corner,
  book bins, device cart, half-moon teacher table with wobble stools.
- **Back wall:** long whiteboard with alphabet card strip and letter tape line, "Reading
  Centers" board with pocket chart, book/toy shelves, rocking chair, door to adjoining room.
- **Entry wall:** main door (A) to hallway (student cubbies outside, restroom B across the
  vestibule), number-calendar pocket chart + dismissal-changes board by the door, trash
  cluster, sink counter, tall cabinets (month-labeled activity crates; cabinet doors double
  as the reading-group tracker with colored construction-paper cards), and a prep nook with
  interior window (clipboards, Drop Box, day-of-week bins).
- **Center:** large carpet with colored assigned letter spots facing the whiteboard; zigzag
  cluster of trapezoid tables; word-work table with black pocket organizers.

## Positions are approximate

The map is schematic, not surveyed — every zone, door, and cabinet is on the correct wall in
the correct order, but distances are eyeballed from photo overlap.
